# Hendy Server Store System (Monorepo)

Hệ thống nền tảng tải phần mềm tốc độ cao chuẩn hóa Production.
- **Frontend:** Next.js 14 ISR (Web Portal) & React Vite (Admin Dashboard)
- **API Core:** Fastify + Drizzle ORM + PostgreSQL 16
- **Edge Layer:** Cloudflare Workers + D1 Database + KV
- **Workers:** BullMQ + Redis 7.2 + ClamAV + VirusTotal API
